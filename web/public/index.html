    About this list

    Built from Arkansas GIS Office road centerlines. Radius is estimated from the centerline, which is digitized coarsely, so estimates can run small and some entries are not real curves. Every entry is a candidate. None is a verified hazard, and none has been checked on the ground.

    Colors show road surface only. They do not show how a curve compares with any other.
